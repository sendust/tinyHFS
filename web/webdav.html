Limitations of the built-in Windows WebDAV client and workarounds


Windows 내장 WebDAV 클라이언트의 제약과 우회 방법





LimitationSymptomWorkaround


WebClient service must be running"The network path was not found" / drive cannot be mappedStart the service and set it to automatic (admin): sc config WebClient start= auto, net start WebClient. Windows Server: install the feature first: Install-WindowsFeature WebDAV-Redirector (PowerShell, reboot).


Password over plain HTTP is refused (Basic auth allowed only over HTTPS by default)Password prompt keeps coming back / "Access denied" although the password is rightRegistry BasicAuthLevel = 2 (see script below), restart WebClient. ⚠ The password is then sent unencrypted — use on a trusted network or VPN only.


File size limit 50 MB (FileSizeLimitInBytes)Copying a larger file fails: "file size exceeds the limit allowed"Raise to the maximum 0xFFFFFFFF (≈ 4 GB). Files over 4 GB cannot be handled by the Windows client at all — use the web file browser (resumable) or a third-party client (below).


Folder listing size limit (FileAttributesLimitInBytes, 1 MB)Folders with thousands of files show an error or appear emptyRaise to 50000000 (see script).


Slow (several seconds per operation)Opening folders / connecting takes longInternet Options → Connections → LAN settings → uncheck Automatically detect settings. Use the IP address instead of the host name.


Copy is done in one piece, no resumeA broken copy of a large file must restart from zeroUse the web file browser (resumable upload/download) for large files.


Free space not reportedDrive shows a wrong / unknown sizeCosmetic. The real free space is shown in the web file browser.






제약증상우회 방법


WebClient 서비스가 실행 중이어야 함"네트워크 경로를 찾을 수 없습니다" / 드라이브 연결 실패관리자 권한으로 서비스 시작 및 자동 시작 설정: sc config WebClient start= auto, net start WebClient. Windows Server는 먼저 기능 설치: Install-WindowsFeature WebDAV-Redirector (PowerShell, 재부팅).


HTTP에서는 비밀번호 전송을 거부 (기본값: Basic 인증은 HTTPS에서만 허용)비밀번호가 맞는데도 입력 창이 계속 뜨거나 "액세스 거부"레지스트리 BasicAuthLevel = 2 설정 (아래 스크립트) 후 WebClient 재시작. ⚠ 비밀번호가 암호화 없이 전송되므로 신뢰할 수 있는 네트워크나 VPN에서만 사용하세요.


파일 크기 50MB 제한 (FileSizeLimitInBytes)큰 파일 복사 시 "파일 크기가 허용 한도를 초과합니다" 오류최대값 0xFFFFFFFF(약 4GB)로 변경. 4GB를 넘는 파일은 Windows 클라이언트로는 처리할 수 없습니다 → 웹 파일 브라우저(이어받기 지원)나 아래의 다른 클라이언트를 사용하세요.


폴더 목록 크기 제한 (FileAttributesLimitInBytes, 1MB)파일이 수천 개인 폴더가 오류 또는 빈 폴더로 보임50000000으로 변경 (아래 스크립트).


느림 (작업마다 몇 초씩 지연)연결, 폴더 열기가 오래 걸림인터넷 옵션 → 연결 → LAN 설정 → 자동으로 설정 검색 체크 해제. 호스트 이름 대신 IP 주소로 연결.


복사가 한 번에 진행되고 이어하기 없음큰 파일 복사가 끊기면 처음부터 다시큰 파일은 웹 파일 브라우저(업로드/다운로드 이어하기 지원)를 사용하세요.


여유 공간 표시 안 됨드라이브 용량이 틀리게 / 알 수 없게 보임표시 문제일 뿐입니다. 실제 여유 공간은 웹 파일 브라우저 상단에 나옵니다.

Notes


참고


    
  
  • The top folder /webdav/ is read-only; files go inside a shared folder.
    • 
  
  • Moving files between different shared folders is not supported (copy instead).
    • 
  
  • WebDAV traffic is plain HTTP. Use it on a trusted network or a VPN.
    • 
  
  • Command line: 
    • 



    
  
  • 최상위 폴더 /webdav/는 읽기 전용입니다. 파일은 공유 폴더 안에 넣으세요.

  • 서로 다른 공유 폴더 사이의 이동은 지원하지 않습니다 (복사를 사용하세요).
